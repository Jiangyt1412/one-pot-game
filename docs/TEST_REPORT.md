## 范围和未完成的验证

这里实现二维保守凸包接触和圆形锅沿约束，没有三维高度、软体变形或流体。凸包填平食物轮廓的凹口和孔洞，使碰撞更保守；点选仍使用真实alpha。跨层相互遮挡是设计的一部分。打乱道具执行层序重排时允许过渡交叠，到合法终点再恢复求解。

代表锅底覆盖来自关卡1、种子1729、模拟5秒，使用128px归一化遮罩及画布118%布局。连续运动、轮廓误差、中心覆盖均为有限模型抽样，不是所有布局保证，也不是浏览器截图或FPS实测。不得把模型CPU耗时换算成手机帧率。

库存检查只验证目标有足够库存、计数守恒和绕过覆盖时能清空库存。固定堆叠与局部补位下的完整空间可解性尚未验证。手动点击使用真实alpha；自动匹配仍使用圆形25点覆盖估计。

浏览器工具此前因安全策略拒绝本地预览地址，本轮没有通过其他方式绕过。新版视口、触控手感、真实中文语音、手机FPS、发热、安全区、PWA安装及离线恢复没有实机验证。当前广告为10秒占位模拟。
