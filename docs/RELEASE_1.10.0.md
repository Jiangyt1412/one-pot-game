# v1.10.0 发布验证

日期：2026-10-14。状态：修订中（WIP）。

## 规则与实现

旧布局在每层前六件候选食物中选尺寸较大的一个，放在中心附近。新版取消这条规则，所有种类随机排列并抽取位置；候选位置受实际旋转凸包和圆形锅边约束，同层保留间距。

下一盘从剩余库存中独立随机预排，选择不读取食物位置或暂存位置。预排类型与当前目标冲突或库存不足时重新核对。初始摆放和打乱中，预排类型部分候选位置轻微倾向一个随机区域；点击后，它只在原本就在空缺附近的食物中获得轻微补位优先级。位置变化仍沿用3.8秒局部补位和同层碰撞约束，不改变物品层数或不透明度。
