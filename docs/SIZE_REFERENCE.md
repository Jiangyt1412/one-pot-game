# 食物份量与大小依据

日期：2026-10-13。版本：1.8.0。尺寸指归一化素材方框边长占游戏画布的比例，身体最长边约为方框的87.5%。这些值是游戏设计尺度，不是厘米测量结果。同一种食物在一局内以及不同关卡中保持同一尺寸。

## 已核实的现实信息

- Johnny’s Selected Seeds的Bolero胡萝卜产品说明给出根长7–8英寸，约17.8–20.3cm；这是具体品种的规格，不能当作所有胡萝卜的固定长度。[生产商资料](https://www.johnnyseeds.com/vegetables/carrots/storage-carrots/bolero-pelleted-f1-carrot-seed-216JP.54.html)
- Syngenta的GH6462甜玉米说明平均穗长8.5英寸、平均穗径2.1英寸，约21.6cm和5.3cm。游戏图片是切下的玉米段，不能把整穗长度套到这段上。[品种资料](https://www.syngentavegetables.com/en-us/product/seed/sweet-corn/gh6462)
- 马里兰大学推广资料说明草莓大小受品种、结果顺序、授粉及环境影响；同一植株先结的果实通常较大。这支持采用明确份量假设，而不能声称所有草莓都有唯一尺寸。[大学推广资料](https://extension.umd.edu/resource/growing-strawberries-home-garden)

据此，整根胡萝卜按大件处理；玉米段按切块处理；单颗草莓按小件处理。这是结合素材所画份量的设计推断，不是对素材进行实物测量。碰撞的“质量”由画布面积近似，与真实密度、重量无关。

## 固定的设计尺寸

| 尺度组 | 素材份量 | 画布比例 |
|---|---|---|
| 小 | 一颗鱼丸 | 0.100 |
| 小 | 一块豆腐、一颗草莓 | 各0.125 |
| 较小 | 一只卷虾、一只馄饨、一只烧卖 | 各0.160 |
| 较小 | 一只饺子、一个香菇、一贯寿司 | 各0.190 |
| 中 | 一片藕、一卷牛肉、一小串葡萄 | 0.200、0.210、0.215 |
| 中 | 一个包子、一个蜜桃、一颗橙子、一段玉米 | 0.220、0.235、0.240、0.240 |
| 中 | 一根蟹棒、一个煎蛋、一朵西兰花、一个甜甜圈、一块蛋糕 | 0.250、0.250、0.270、0.270、0.300 |
| 大 | 一支雪糕、一根烤肠、一只鸡腿 | 0.350、0.370、0.380 |
| 大 | 一片生菜、一块西瓜、一片白菜、一根带叶胡萝卜 | 0.400、0.410、0.420、0.430 |

当前素材是份量插画，不能验证鸡腿、饺子、鱼丸、切片水果等各自的唯一现实尺寸。此次没有找到能统一对应这些插画全部28种份量的权威测量数据；表中全部画布比例均为公开的设计假设。最大/最小4.3倍为表中游戏比例之比，不宣称普遍真实比例。对小食物未按单粒葡萄缩小，因为图片本身画的是一串葡萄。
