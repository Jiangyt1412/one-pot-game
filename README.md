# 一锅端（修订中）

> **状态：修订中（WIP）**。当前保存版本为 **1.8.0**，快照日期为 **2026-10-14**。后续继续修订难度、动画表现和手机适配。

手机竖屏休闲收集游戏，React + TypeScript + Vite，Canvas绘制28种食物，50关。当前版本1.8.0，完整前端/PWA交付。

## 本轮修改

- 按清理后的食物alpha轮廓生成12边凸包。同层食物碰到后会反弹、互相推开，较小食物更容易被推走；跨层仍保留遮挡。
- 初始摆放、打乱和暂存撤回都使用轮廓装填。同层不会从互相叠在一起的状态开局，较长食物可以靠近锅沿，圆形边界约束实际旋转轮廓。
- 漂动使用持续速度，普通周期约26–28秒，比上一版稍快；水平/竖直驱动幅度提高到0.058/0.050画布比例。碰撞会改变后续位置，不再每帧回到固定锚点。
- 点击后优先带动同层邻居，再带动临近下层，最多五件。局部补位约3.8秒并受碰撞约束；其余碰到这些食物的同层物品也会被推开。没有点击不会启动补位任务，深度及不透明绘制保持稳定。
- 按素材所画的整件或切块区分大小。全库最大/最小尺寸比例4.3，白菜、胡萝卜、鸡腿明显大于鱼丸、草莓、豆腐块；每个种类只有一个固定尺寸。现实依据和没有核实的假设见docs/SIZE_REFERENCE.md。

沿用大目标盘、上一个下两个的三角形槽位、满盘飞出360ms/新盘飞入380ms；每关99件、15种，全库28种轮换，同类固定尺寸。配色、语音暂存解锁及道具规则保留。素材及生成记录见docs/ART_DIRECTION_V15.md。

预览：http://localhost:4173/。刷新加载新构建；离线缓存更新可能需要再次刷新。

## 运行

```bash
npm install # 安装依赖
npm run dev # 开发服务，默认5173端口
npm run build # TypeScript检查、生产构建、离线缓存生成
npm run preview # 正式预览，默认4173端口
npm test # 规则、运动连续性、轮廓清理、广告及存档测试
npm run test:motion # 80组连续运动及点击后的局部布局、碰撞和圆形范围数值检查
npm run test:levels # 50关乘20个种子，1000局随机目标及库存检查，不验证几何可解性
npm run test:browser # 可选浏览器烟雾测试；需要另行启动dev，本轮未执行
```

dist可部署到静态HTTPS服务器根目录；不能直接用file://打开。手机真实语音能力取决于浏览器、安全上下文、授权和识别服务。开发模式有模拟识别按钮，正式构建默认隐藏模拟入口。

## 规则

1. 目标盘三个位置收齐同类食物后消除，满盘飞走，新盘飞入。
2. 非目标食物进入暂存。暂存只存不消，同类三个也不消除；全部格子占满就失败。解锁第4格后，3件暂存可以继续游戏，第4件填满时失败。
3. 目标刷新或解锁时随机产生新目标；只有匹配的暂存食物才移到目标盘。
4. 点击暂存区的锁、点击麦克风、说「蒋雨童最棒」，本关暂存从3扩到4；每关一次，重开或下一关恢复3格。
5. 两个锁住的目标盘分别说「蒋雨童发大财」解锁，与暂存格独立。
6. 道具用完后说「蒋雨童是天才」领取所选道具+1，再次点击使用。
7. 失败后完整观看10秒占位广告可复活一次，提前退出无奖励。尚未接入真实广告网络。
8. 存档记录关卡、道具、设置和已领补给，不存半局布局。尊重已保存的减少动画选项。

语音只在点击麦克风后启动。口令匹配允许空格和标点，不接受不同姓名或否定句，不检测音量。没有账号后端或服务器防作弊。

## 实现与验证边界

食物和固定尺寸表在src/config/items.ts，关卡在src/config/levels.ts，口令在src/config/gameConfig.ts。原有23种素材来自约251px图集单元，没有增加原生细节；新增5种独立原图更大。资源来源及准确提示词见docs/ART_DIRECTION_V15.md。

SpriteSanitizer移除不属于主体的独立图集碎片，再统一透明边距。FoodHitTest用当前尺寸、旋转、绘制顺序和主体alpha判定。露出的下层像素可以点击，被上层不透明像素遮挡的位置不能穿透点击。图像描边、圆形锅边和点击场景保持同一坐标体系。

FloatingScene保存位置和速度，按physical depth分组运行接触求解，1/30秒等较长帧会细分为最多1/60秒的子步。碰撞按面积近似质量，速度相互传递；这里是二维凸包刚体近似，没有真实三维形变或流体。凸包会把虾的内弯及藕片孔洞视为实体，这是保守碰撞范围；点击仍使用真实alpha，孔洞可触及下层。

物品数量仍为99。为了使大小不同的食物同层有摆放和漂动空间，层数按轮廓装填；配置depthLayers用于计算99件初始棋盘的每层数量上限；清空部分食物后重排会相应减少层数。点击只启动局部位移，不会周期性换层、把上层变透明或优先抬高目标食物。暂停冻结速度、补位和位置；减少动画选项禁用普通漂动并即时完成补位。打乱用650ms平滑插值，到达新的合法装填位置后恢复接触求解。

批量检查使用同一引擎验证随机目标库存足够、库存守恒，以及在忽略几何遮挡时的库存通关。该脚本显式绕过覆盖检查，不证明真人操作或固定堆叠的可解性。旧版等待自动显露的通关证明已撤销；新版所有布局的几何可解性尚未验证。手动点击用实际像素轮廓，自动匹配使用圆形25点覆盖估计。

实际检查结果见docs/TEST_REPORT.md。浏览器工具之前因安全策略拒绝本地预览，本轮没有绕过访问限制，因此新版完整界面的视口、真实触控性能和真实语音尚未实测。源码构建、运动测试、素材检查图和覆盖数值不能替代浏览器或手机验收。
